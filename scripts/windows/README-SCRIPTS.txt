Jokerz AIO — Windows

1) Install Node LTS  https://nodejs.org  (Add to PATH)
2) Install Google Chrome
3) Double-click  INSTALL-JOKERZ.bat   (in the zip folder)
4) Double-click  START-JOKERZ.bat     (starts engine + UI + browser)

INSTALL runs npm + Patchright + Chromium.
If Chrome is missing it continues with bundled Chromium.

Harvest does not auto-start: Settings → Harvesters → Play

STOP-JOKERZ.bat closes the AIO.
