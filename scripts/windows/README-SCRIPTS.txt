Jokerz AIO — Windows

1) Install Node LTS  https://nodejs.org  (Add to PATH)
2) Install Google Chrome (recommended for logins)
3) Double-click  INSTALL-JOKERZ.bat   (first time only)
4) Double-click  START-JOKERZ.bat     (one window: checks, installs what is missing,
                                       starts engine + UI, restarts them if they crash,
                                       opens the browser)
5) Optional: CREATE-SHORTCUT.bat puts a "Jokerz AIO" icon on your Desktop.

Keep the START window open while you use the app. Ctrl+C (or close it) stops everything.
STOP-JOKERZ.bat closes any AIO window left open.

Logs: logs\jokerz-YYYY-MM-DD.log (14 days). Dashboard → Logs to search / export ZIP.
Problems: Dashboard → Diagnostics → Download report.
Updates: Settings → General → Updates.

Tip: running from a Google Drive / OneDrive folder works, but sync can lock files.
Copying the folder to e.g. C:\JokerzAIO is more reliable.
